# China Travel & Business Trip Quick Guide｜2026

境外员工来华商务出行指南（中英双语单页）。

从出发前准备，到入境、支付、交通、酒店与紧急联系方式，一页覆盖来华商务出行所需信息。

## 内容

12 个章节：出发前确认、入境流程、支付方式、支付宝/微信支付设置、支付问答、机票与酒店预订、
打车与导航、城市间高铁出行、酒店与日常生活、紧急联系方式、飞机舱位对比、深圳外籍友好酒店推荐。

## 结构

```
index.html      单页全部内容（HTML + 内联 CSS/JS，无外部依赖）
images/         25 张操作截图
.nojekyll       关闭 GitHub Pages 的 Jekyll 处理
```

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 用浏览器打开也可以。

## 说明

- 无构建步骤、无外部 CDN 依赖，改完 `index.html` 直接提交即生效。
- 图片为外部文件而非内联 base64，因此 `index.html` 与 `images/` 需一起保留。
- 已适配手机（320–430px）、平板与桌面；所有截图支持点击全屏放大。
- 兼容微信内置浏览器（X5 内核），相关处理在代码中有注释标注。
